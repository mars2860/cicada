## How to build

1. Install Sloeber IDE https://github.com/Sloeber/arduino-eclipse-plugin/releases/
2. Run Sloeber IDE. Go to the menu item Sloeber->Preferences->Platforms and Boards. Download the latest version of ESP8266 platform and ESP32 platform
3. Select the build configuration for the specified cicada board
4. Press "Verify Sketch"
